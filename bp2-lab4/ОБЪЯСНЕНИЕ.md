## Что такое бинарное дерево поиска (BST)?

**Бинарное дерево поиска** - это структура данных, где каждый узел имеет максимум двух детей, и выполняется правило:
- Все значения в **левом поддереве** меньше значения узла
- Все значения в **правом поддереве** больше значения узла

### Визуализация BST:
```
        50
       /  \
      30   70
     /  \    \
    20  40   80
```

**Свойства:**
- Узел 50: левые дети (20, 30, 40) < 50 < правые дети (70, 80)
- Поиск, вставка, удаление: O(log n) в среднем случае
- Обход inorder дает отсортированную последовательность

## Упражнение 8: Сумма всех узлов

### Что делает программа
Создает бинарное дерево поиска из введенных чисел и вычисляет сумму всех значений в дереве.

### Как работает

#### Структура узла:
```cpp
struct Node {
    int data;        // Значение узла
    Node* left;      // Указатель на левого ребенка
    Node* right;     // Указатель на правого ребенка
};
```

#### Основные операции:

**1. Вставка узла (`insertRec`)**
```cpp
Node* insertRec(Node* node, int val) {
    if (node == nullptr) {
        return new Node(val);  // Создаем новый узел
    }
    
    if (val < node->data) {
        node->left = insertRec(node->left, val);   // Идем влево
    } else if (val > node->data) {
        node->right = insertRec(node->right, val); // Идем вправо
    }
    
    return node;
}
```

**Алгоритм:**
- Если дерево пустое → создаем корень
- Если значение меньше текущего узла → вставляем в левое поддерево
- Если значение больше → вставляем в правое поддерево
- Дубликаты игнорируются

**2. Вычисление суммы (`sumRec`)**
```cpp
int sumRec(Node* node) {
    if (node == nullptr) {
        return 0;  // Пустое дерево = сумма 0
    }
    
    // Сумма = текущий узел + сумма левого + сумма правого
    return node->data + sumRec(node->left) + sumRec(node->right);
}
```

**Принцип работы:**
- Рекурсивно обходим все узлы
- Суммируем значение текущего узла с суммами поддеревьев
- Базовый случай: пустой узел возвращает 0

### Пример работы:
```
Ввод: 50, 30, 70, 20, 40, 80

Построенное дерево:
        50
       /  \
      30   70
     /  \    \
    20  40   80

Обход inorder (отсортированный): 20 30 40 50 70 80
Сумма всех узлов: 20+30+40+50+70+80 = 290
```

## Упражнение 15: Подсчет узлов-листьев

### Что делает программа
Создает BST и подсчитывает количество **узлов-листьев** (узлов без детей).

### Как работает

#### Что такое узел-лист?
**Узел-лист (leaf node)** - это узел, у которого нет ни левого, ни правого ребенка.

```
        50
       /  \
      30   70      Листья: 20, 40, 80
     /  \    \     Внутренние узлы: 50, 30, 70
    20  40   80
```

#### Основные операции:

**1. Подсчет листьев (`countLeavesRec`)**
```cpp
int countLeavesRec(Node* node) {
    if (node == nullptr) {
        return 0;  // Пустой узел
    }
    
    // Проверяем: нет ли детей?
    if (node->left == nullptr && node->right == nullptr) {
        return 1;  // Это лист!
    }
    
    // Считаем листья в поддеревьях
    return countLeavesRec(node->left) + countLeavesRec(node->right);
}
```

**Алгоритм:**
- Если узел пустой → 0 листьев
- Если у узла нет детей → это лист (возвращаем 1)
- Иначе → рекурсивно считаем листья в левом и правом поддеревьях

**2. Подсчет внутренних узлов (`countInternalRec`)**
```cpp
int countInternalRec(Node* node) {
    // Пустой узел или лист → не внутренний
    if (node == nullptr || 
        (node->left == nullptr && node->right == nullptr)) {
        return 0;
    }
    
    // Текущий узел внутренний + считаем в поддеревьях
    return 1 + countInternalRec(node->left) + countInternalRec(node->right);
}
```

**3. Вывод всех листьев (`printLeavesRec`)**
```cpp
void printLeavesRec(Node* node) {
    if (node == nullptr) return;
    
    // Если лист → выводим
    if (node->left == nullptr && node->right == nullptr) {
        std::cout << node->data << " ";
    }
    
    // Продолжаем обход
    printLeavesRec(node->left);
    printLeavesRec(node->right);
}
```

### Пример работы:
```
Ввод: 50, 30, 70, 20, 40, 60, 80

Построенное дерево:
        50
       /  \
      30   70
     /  \  / \
    20  40 60 80

Обход inorder: 20 30 40 50 60 70 80
Узлы-листья: 20 40 60 80

Статистика:
  Количество листьев: 4
  Количество внутренних узлов: 3 (30, 50, 70)
  Высота дерева: 3
```

## Упражнение 20: Полная система управления BST

### Что делает программа
Комплексная программа для работы с бинарным деревом поиска со всеми основными операциями: вставка, удаление, поиск, различные виды обхода, статистика.

### Как работает

#### Все операции BST:

**1. Вставка (`insert`)**
Уже описана выше - добавляет узел в правильную позицию.

**2. Поиск (`search`)**
```cpp
Node* searchRec(Node* node, int val) {
    if (node == nullptr || node->data == val) {
        return node;  // Найден или не существует
    }
    
    if (val < node->data) {
        return searchRec(node->left, val);   // Ищем слева
    }
    return searchRec(node->right, val);      // Ищем справа
}
```

**Сложность:** O(log n) в среднем, O(n) в худшем случае

**3. Удаление (`deleteRec`) - самая сложная операция**

Есть **3 случая удаления:**

**Случай 1: Узел-лист (без детей)**
```
Удаляем 20:
    50              50
   /  \            /  \
  30   70   →     30   70
 /                     
20                    
```
Просто удаляем узел.

**Случай 2: Узел с одним ребенком**
```
Удаляем 30:
    50              50
   /  \            /  \
  30   70   →     20   70
 /                     
20                    
```
Заменяем узел его единственным ребенком.

**Случай 3: Узел с двумя детьми**
```
Удаляем 50:
    50              60
   /  \            /  \
  30   70   →     30   70
      /  \             \
     60  80            80
```
Находим **inorder successor** (минимальный узел в правом поддереве), копируем его значение, удаляем successor.

**Код:**
```cpp
Node* deleteRec(Node* node, int val) {
    if (node == nullptr) return node;
    
    // Поиск узла
    if (val < node->data) {
        node->left = deleteRec(node->left, val);
    } else if (val > node->data) {
        node->right = deleteRec(node->right, val);
    } else {
        // Узел найден
        
        // Случай 1: Лист
        if (node->left == nullptr && node->right == nullptr) {
            delete node;
            return nullptr;
        }
        
        // Случай 2: Один ребенок
        if (node->left == nullptr) {
            Node* temp = node->right;
            delete node;
            return temp;
        }
        if (node->right == nullptr) {
            Node* temp = node->left;
            delete node;
            return temp;
        }
        
        // Случай 3: Два ребенка
        Node* successor = findMin(node->right);  // Минимум справа
        node->data = successor->data;            // Копируем значение
        node->right = deleteRec(node->right, successor->data); // Удаляем successor
    }
    
    return node;
}
```

**4. Виды обхода дерева:**

**Inorder (левый - корень - правый)** - дает отсортированную последовательность
```cpp
void inorderRec(Node* node) {
    if (node != nullptr) {
        inorderRec(node->left);      // Левое поддерево
        std::cout << node->data;     // Корень
        inorderRec(node->right);     // Правое поддерево
    }
}
```

**Preorder (корень - левый - правый)** - используется для копирования дерева
```cpp
void preorderRec(Node* node) {
    if (node != nullptr) {
        std::cout << node->data;     // Корень
        preorderRec(node->left);     // Левое поддерево
        preorderRec(node->right);    // Правое поддерево
    }
}
```

**Postorder (левый - правый - корень)** - используется для удаления дерева
```cpp
void postorderRec(Node* node) {
    if (node != nullptr) {
        postorderRec(node->left);    // Левое поддерево
        postorderRec(node->right);   // Правое поддерево
        std::cout << node->data;     // Корень
    }
}
```

**Level-order (по уровням)** - использует очередь
```cpp
void levelOrder() {
    std::queue<Node*> q;
    q.push(root);
    
    while (!q.empty()) {
        Node* current = q.front();
        q.pop();
        
        std::cout << current->data << " ";
        
        if (current->left) q.push(current->left);
        if (current->right) q.push(current->right);
    }
}
```

**Пример обходов:**
```
Дерево:
        50
       /  \
      30   70
     /  \    \
    20  40   80

Inorder:    20 30 40 50 70 80  (отсортировано!)
Preorder:   50 30 20 40 70 80  (корень первым)
Postorder:  20 40 30 80 70 50  (корень последним)
Level-order: 50 30 70 20 40 80 (по уровням)
```

**5. Высота дерева (`height`)**
```cpp
int heightRec(Node* node) {
    if (node == nullptr) {
        return 0;
    }
    return 1 + std::max(heightRec(node->left), heightRec(node->right));
}
```

**Высота** = максимальная длина пути от корня до листа.

**6. Проверка сбалансированности (`isBalanced`)**
```cpp
bool isBalancedRec(Node* node) {
    if (node == nullptr) return true;
    
    int leftHeight = heightRec(node->left);
    int rightHeight = heightRec(node->right);
    
    // Разница высот не должна превышать 1
    if (std::abs(leftHeight - rightHeight) > 1) {
        return false;
    }
    
    return isBalancedRec(node->left) && isBalancedRec(node->right);
}
```

**Сбалансированное дерево:**
```
    50          Высоты: left=2, right=2
   /  \         Разница: |2-2| = 0 ≤ 1 ✓
  30   70       СБАЛАНСИРОВАНО
 /  \    \
20  40   80
```

**Несбалансированное дерево:**
```
    50          Высоты: left=3, right=1
   /  \         Разница: |3-1| = 2 > 1 ✗
  30   70       НЕ СБАЛАНСИРОВАНО
 /  
20  
/
10
```

**7. Минимум и максимум**
```cpp
// Минимум - самый левый узел
int findMinValue() {
    Node* current = root;
    while (current->left != nullptr) {
        current = current->left;
    }
    return current->data;
}

// Максимум - самый правый узел
int findMaxValue() {
    Node* current = root;
    while (current->right != nullptr) {
        current = current->right;
    }
    return current->data;
}
```

## Сложность операций BST

| Операция | Средний случай | Худший случай |
|----------|----------------|---------------|
| Поиск    | O(log n)       | O(n)          |
| Вставка  | O(log n)       | O(n)          |
| Удаление | O(log n)       | O(n)          |
| Обход    | O(n)           | O(n)          |

**Худший случай** возникает при вырожденном дереве (все узлы в одну сторону):
```
50
 \
  60
   \
    70
     \
      80  ← Превращается в связный список!
```

## Ключевые концепции

### Бинарное дерево поиска (BST):
- Левое поддерево < Корень < Правое поддерево
- Эффективный поиск: O(log n) в среднем
- Inorder обход дает отсортированную последовательность

### Типы узлов:
- **Корень (root)** - верхний узел
- **Лист (leaf)** - узел без детей
- **Внутренний узел (internal)** - узел с детьми

### Операции удаления:
1. Лист → просто удалить
2. Один ребенок → заменить узел ребенком
3. Два ребенка → заменить inorder successor'ом

### Виды обхода:
- **Inorder** - отсортированный вывод
- **Preorder** - копирование структуры
- **Postorder** - удаление дерева
- **Level-order** - обход по уровням (BFS)

### Баланс дерева:
- Сбалансированное: разница высот ≤ 1
- Несбалансированное: операции деградируют до O(n)
- Решение: AVL-деревья, красно-черные деревья
