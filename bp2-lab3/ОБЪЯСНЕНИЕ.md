## Упражнение 7: Сортировка с помощью стеков

### Что делает программа
Программа сортирует числа в порядке возрастания, используя две стеки (stack). Пользователь вводит числа, и программа упорядочивает их с помощью алгоритма сортировки вставками через стеки.

### Как работает

#### Структура данных: Класс `Stiva` (Стек)
```cpp
class Stiva {
private:
    struct Node {
        int value;      // Значение элемента
        Node* next;     // Указатель на следующий элемент
    };
    Node* top;          // Указатель на вершину стека
};
```

Стек работает по принципу LIFO (Last In, First Out) - последний вошел, первый вышел.

#### Основные операции стека:
1. **`adaugare(int val)`** - Добавить элемент на вершину стека
   - Создает новый узел
   - Помещает его на вершину (top)
   
2. **`eliminare()`** - Удалить и вернуть элемент с вершины
   - Сохраняет значение вершины
   - Удаляет узел
   - Возвращает значение

3. **`varf()`** - Посмотреть значение на вершине (без удаления)

4. **`isEmpty()`** - Проверить, пуст ли стек

#### Алгоритм сортировки:

**Шаг 1: Ввод данных**
```cpp
// Пользователь вводит числа
// Каждое число добавляется в stiva1
```

**Шаг 2: Сортировка**
```cpp
while (!stiva1.isEmpty()) {
    int temp = stiva1.eliminare();  // Берем элемент из stiva1
    
    // Переносим из stiva2 в stiva1 все элементы больше temp
    while (!stiva2.isEmpty() && stiva2.varf() > temp) {
        stiva1.adaugare(stiva2.eliminare());
    }
    
    // Помещаем temp в правильную позицию в stiva2
    stiva2.adaugare(temp);
}
```

**Принцип работы:**
- `stiva2` всегда содержит отсортированные элементы (по убыванию сверху вниз)
- Для каждого нового элемента из `stiva1`:
  - Временно перемещаем большие элементы обратно в `stiva1`
  - Вставляем элемент в правильную позицию в `stiva2`
  - Возвращаем перемещенные элементы

**Шаг 3: Вывод результата**
```cpp
stiva2.afisare();  // Выводит числа в порядке возрастания
```

### Пример работы:
```
Ввод: 5, 2, 8, 1, 9
Процесс:
  stiva1: [5, 2, 8, 1, 9]  stiva2: []
  stiva1: [2, 8, 1, 9]     stiva2: [5]
  stiva1: [8, 1, 9]        stiva2: [5, 2]
  stiva1: [1, 9]           stiva2: [8, 5, 2]
  stiva1: [9]              stiva2: [8, 5, 2, 1]
  stiva1: []               stiva2: [9, 8, 5, 2, 1]
  
Вывод (сверху вниз): 9 8 5 2 1
Вывод (снизу вверх): 1 2 5 8 9 ✓
```

## Упражнение 10: Система управления товарами

### Что делает программа
Программа управляет инвентарем товаров с помощью двусвязного списка. Каждый товар имеет код, название, количество на складе и цену. Система позволяет добавлять, удалять, искать товары, управлять складом и сортировать по цене.

### Как работает

#### Структура данных: Класс `Articol` (Товар)
```cpp
class Articol {
private:
    int cod;              // Код товара
    std::string nume;     // Название
    int stoc;             // Количество на складе
    double pret;          // Цена
};
```

#### Структура данных: Класс `Lista_articol` (Список товаров)
```cpp
class Lista_articol {
private:
    struct Node {
        Articol* inf;     // Указатель на товар
        Node* next;       // Указатель на следующий узел
        Node* prev;       // Указатель на предыдущий узел
    };
    Node* sant1;          // Сторожевой узел (начало)
    Node* sant2;          // Сторожевой узел (конец)
};
```

**Сторожевые узлы (Sentinel nodes):**
- `sant1` и `sant2` - фиктивные узлы на границах списка
- Упрощают операции вставки/удаления (не нужны проверки на NULL)
- Реальные данные находятся между `sant1` и `sant2`

```
sant1 <-> [товар1] <-> [товар2] <-> [товар3] <-> sant2
```

#### Основные операции:

**1. Добавление товара (`adaugare`)**
```cpp
// Товары добавляются в отсортированном порядке по коду
// Алгоритм:
// 1. Найти позицию, где код нового товара меньше следующего
// 2. Вставить новый узел между текущим и следующим
// 3. Обновить указатели prev и next
```

**2. Удаление товара (`stergere`)**
```cpp
// Удаление по коду товара
// Алгоритм:
// 1. Найти узел с нужным кодом
// 2. Связать предыдущий узел со следующим
// 3. Удалить найденный узел
```

**3. Поиск товара (`cautare`)**
```cpp
// Поиск по коду
// Возвращает указатель на товар или nullptr
```

**4. Управление складом:**

**Поступление товара (`intrareStoc`)**
```cpp
// Увеличивает количество товара на складе
articol->setStoc(articol->getStoc() + cantitate);
```

**Продажа/расход товара (`iesireStoc`)**
```cpp
// Уменьшает количество товара
// Если остаток = 0, товар автоматически удаляется из списка
if (articol->getStoc() == 0) {
    stergere(cod);  // Автоматическое удаление
}
```

**5. Сортировка по цене (`sortarePret`)**
```cpp
// Сортировка пузырьком (Bubble Sort)
// Сравнивает соседние элементы и меняет их местами
// Продолжает до тех пор, пока список не станет отсортированным
```

**6. Отображение:**
- **`afisare()`** - Вывод списка от начала к концу (sant1 → sant2)
- **`afisareInversa()`** - Вывод списка от конца к началу (sant2 → sant1)

### Меню программы:
```
1. Adaugare articol        - Добавить товар
2. Stergere articol        - Удалить товар
3. Cautare articol         - Найти товар
4. Modificare articol      - Изменить товар
5. Intrare stoc            - Поступление на склад
6. Iesire stoc             - Продажа/расход
7. Afisare lista           - Показать список
8. Afisare inversa         - Показать в обратном порядке
9. Sortare dupa pret       - Сортировать по цене

```

## Упражнение 14: Игра "Красная гусыня"

### Что делает программа
Симулирует карточную игру между двумя игроками с колодой из 16 карт (по 8 карт каждому). Игроки по очереди кладут карты на стол. Когда цвета двух последних карт совпадают (обе красные или обе черные), игрок, положивший вторую карту, забирает все карты со стола. Побеждает тот, у кого остались карты, когда противник остался без карт.

### Как работает

#### Структура данных: Очередь (Queue)
```cpp
struct nod {
    int valoare;        // Значение карты (1-8)
    string suit;        // Масть: "Inima"(червы), "Romb"(бубны), "Trefla"(трефы), "Pica"(пики)
    string culoare;     // Цвет: "rosie"(красная) или "neagra"(черная)
    nod *urm;           // Указатель на следующую карту
};
```

Очередь работает по принципу FIFO (First In, First Out) - первый вошел, первый вышел.

#### Основные функции:

**1. `adauga_sfarsit()` - Добавить карту в конец очереди**
```cpp
// Добавляет новую карту в конец пачки
// Если пачка пуста: prim = ultim = новая_карта
// Иначе: ultim->urm = новая_карта; ultim = новая_карта
```

**2. `scoate_primul()` - Взять первую карту из очереди**
```cpp
// Удаляет и возвращает первую карту из пачки
// prim = prim->urm (сдвигаем начало)
// Возвращает удаленную карту
```

**3. `muta_masa_la_pachet()` - Переместить все карты со стола в пачку**
```cpp
// Берет все карты со стола и добавляет их в конец пачки игрока
// Связывает последнюю карту пачки с первой картой стола
// Обновляет указатель на последнюю карту
// Очищает стол (masa_prim = masa_ultim = NULL)
```

**4. `numar_carti()` - Подсчитать количество карт**
```cpp

```

#### Алгоритм игры:

**Инициализация:**
```cpp
1. Создать две колоды по 8 карт каждая:
   - Игрок 1: 8 карт (значения 1-8, разные масти)
   - Игрок 2: 8 карт (значения 1-8, разные масти)
   - Червы (Inima) и Бубны (Romb) = красные
   - Трефы (Trefla) и Пики (Pica) = черные
```

**Игровой цикл:**
```cpp
while (у обоих игроков есть карты && рунд < 50) {
    1. Игрок 1 берет верхнюю карту и кладет на стол
    2. Запоминаем цвет первой карты (culoare1)
    
    3. Игрок 2 берет верхнюю карту и кладет на стол
    4. Запоминаем цвет второй карты (culoare2)
    
    5. Проверяем совпадение цветов:
       
       Если culoare1 == culoare2 (цвета совпадают):
         - Игрок 2 (положивший вторую карту) забирает ВСЕ карты со стола
         - Карты добавляются в конец его пачки
         - Стол очищается
       
       Если culoare1 != culoare2 (цвета не совпадают):
         - Карты остаются на столе
         - Игра продолжается
}
```

**Условие победы:**
```cpp
if (juc1_prim == NULL)      // Игрок 1 без карт
    → Игрок 2 ВЫИГРЫВАЕТ!
else if (juc2_prim == NULL) // Игрок 2 без карт
    → Игрок 1 ВЫИГРЫВАЕТ!
else                        // Достигнут лимит раундов (50)
    → НИЧЬЯ!
```

### Визуализация структур данных:

```
Пачка Игрока 1 (очередь):
  prim → [карта1] → [карта2] → [карта3] → ... → [картаN] ← ultim
         ↑ берем отсюда                          ↑ добавляем сюда

Стол (очередь):
  prim → [карта1] → [карта2] → [карта3] ← ultim
  
Когда выпадает красная карта:
  1. Все карты со стола переносятся в конец пачки противника
  2. Стол очищается (prim = ultim = NULL)
```

## Ключевые концепции

### Динамические структуры данных:
1. **Стек (Stack)** - LIFO, операции только с вершиной
2. **Очередь (Queue)** - FIFO, добавление в конец, удаление из начала
3. **Двусвязный список (Doubly Linked List)** - навигация в обе стороны

### Управление памятью:
- `new` - выделение памяти
- `delete` - освобождение памяти
- Деструкторы для автоматической очистки

### Алгоритмы:
- Сортировка вставками (через стеки)
- Сортировка пузырьком (двусвязный список)
- Симуляция игрового процесса (очереди)
